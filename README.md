# 🎓 Smart Seat Recommendation System (AD Project)

## 📌 프로젝트 소개

Smart Seat Recommendation System은 대학 강의실 내 좌석 부족 및 콘센트 사용 문제를 해결하기 위한 AI 기반 스마트 좌석 추천 서비스입니다.

학생이 K-Card를 태그하면 현재 강의실의 실시간 좌석 현황을 확인하고, AI가 콘센트 사용 가능 여부와 좌석 위치를 고려하여 최적의 좌석을 추천합니다.

또한 기존 CCTV와 AI 객체 인식 기술을 활용하여 강의실의 좌석 점유 상태를 자동으로 분석하고 데이터베이스를 실시간으로 업데이트합니다.

---

## 🎯 문제 정의

대학생들은 다음과 같은 문제를 자주 겪습니다.

* 빈 좌석을 찾기 위해 강의실을 직접 돌아다녀야 함
* 노트북 사용을 위한 콘센트 좌석 부족
* 강의실 혼잡도 확인 불가
* 좌석 현황을 수작업으로 확인해야 함

본 프로젝트는 이러한 문제를 해결하기 위해 기획되었습니다.

## 💡 주요 기능

### 1. 강의실 선택

사용자가 이용할 강의실을 선택합니다.

지원 강의실

* 미래관 424호
* 미래관 445호
* 미래관 447호
* 미래관 611호

### 2. K-Card 태그

학생증(K-Card)을 태그하면 비콘이 이를 감지합니다.

### 3. 실시간 좌석 데이터 조회

서버가 강의실의 좌석 상태 데이터를 조회합니다.

확인 정보

* 전체 좌석 수
* 빈 좌석 수
* 콘센트 사용 가능 좌석 수

### 4. AI 추천 좌석 제공

AI가 다음 조건을 고려하여 최적의 좌석을 추천합니다.

* 빈 좌석 여부
* 콘센트 사용 가능 여부
* 강의실 위치
* 시야 확보

### 5. AI CCTV 분석

기존 CCTV 영상을 활용하여

* 좌석 점유 여부 감지
* 빈 좌석 계산
* 강의실 혼잡도 분석

을 수행합니다.
